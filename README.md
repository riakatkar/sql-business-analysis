# SQL Business Analysis Project

## 📊 Overview
This project analyzes customer orders and payments data using SQL to extract
business insights related to revenue, customer behavior, and performance trends.

## 🛠 Tools Used
- MySQL
- SQL (Joins, Subqueries, Aggregations, CASE)
- Git & GitHub

## 📂 Database Tables
- customers
- orders
- payments

## 🎯 Key Analysis Performed
- Customer Lifetime Value (LTV)
- Repeat vs One-time customer segmentation
- Average Order Value (AOV)
- Revenue by city
- Monthly revenue trends
- Payment success vs failure analysis

## 🎯 Key Insights
- Repeat customers contribute higher overall revenue
- A small group of customers generates most revenue
- Certain cities outperform others in sales
- Payment failures directly impact revenue realization

## 🚀 Conclusion
This project demonstrates strong SQL fundamentals and business-oriented thinking.
It is suitable for entry-level Data Analyst / Business Analyst roles.
